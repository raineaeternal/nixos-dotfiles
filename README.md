# Raine's NixOS config

Features:
 - [Niri](https://github.com/yalter/niri)
 - Alacritty
 - just-one-more-repo
 - chaotic-nyx

 This flake-based config does come with AMD and nvidia GPU configs, though it is highly recommended that you use an AMD GPU. Plasma 6 and SDDM module is included should you not want to use Niri (highly recommend! Niri is a Scrollable-tiling window manager that _imo_ does a lot better of a job than Hyprland does tiling.).

 A lot of the game specific stuff can also be removed if you don't play FFXIV or gacha games.
